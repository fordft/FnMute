# Changelog

## 1.2.0 — 2026-10-07

First public release.

- Physical Fn detection keeps output muted throughout dictation, including when Gemini clears the macOS Fn modifier flag.
- Previous mute and volume settings are restored on release, quit, and sleep.
- Native Launch at Login is enabled on first launch from Applications and can be changed in the menu.
- First-launch guidance explains the required Input Monitoring permission.
- Universal app supports Apple Silicon and Intel Macs running macOS 13 or later.
- Drag-and-drop DMG, ZIP download, and SHA-256 checksums.
- Fn-state regression tests and automated macOS build workflow.

The initial public downloads are ad hoc signed and not Developer ID notarized.
